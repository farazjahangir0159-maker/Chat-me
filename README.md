# CHAT ME — Modern Real-Time Messaging & Social Platform
> Inspired by WhatsApp, engineered for privacy, personalization, and real-time interaction.

Version: **2.0.0**  
Product Type: **Social Messaging Web Application + PWA**

---

## 🚀 Quick Start

### Live App
Visit: [https://farazjahangir0159-maker.github.io/Chat-me/](https://farazjahangir0159-maker.github.io/Chat-me/)

### Run Locally
1. Open **`index.html`** directly in Chrome, Edge, Safari, or Firefox.
2. The application runs in standalone mode with complete cross-device real-time sync powered by Cloud Mesh.

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| **Real-Time Chat** | Instant bi-directional messaging with typing indicators, timestamps, date dividers |
| **Voice Messages** | Record and send voice notes with waveform player and progress bar |
| **Photo & Video Sharing** | Send photos and videos with auto-compression and streaming playback |
| **Status / Stories** | 24-hour status updates visible to all chat partners |
| **Profile Photos** | Set and view profile photos across all chats and search |
| **Audio/Video Calls** | Live audio and video calling with WebRTC |
| **Emoji & Stickers** | Full emoji picker and custom sticker library |
| **Dark Mode** | Light/Dark theme toggle |
| **Cross-Device Sync** | Real-time sync across all devices via Cloud Mesh |
